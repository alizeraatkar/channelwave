# Sources in Home tabs

Use the single Home header's three-dot button, then **Add from Library → Source**.
Search sources already stored in the current account's Library and select a plus
row. The shortcut saves immediately; **Done** returns to Home without changing
the selected tab. Scroll the top tab strip to select the new source.

Source tabs use the existing grid/list collections and source-scoped playback
queue. Empty sources remain valid. Disconnected browsing shows saved audio only.
Removing a shortcut preserves its source; removing a source from Library removes
its shortcut and resets selection to All if needed. Re-adding a source does not
recreate its former shortcut. Source name changes update the shortcut on refresh.
